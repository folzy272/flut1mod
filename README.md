# Завдання 1 — Основи Dart: класи та колекції

Реалізовано абстрактний `LibraryItem(title, year, describe())`, похідні `Book` і `Magazine` та `Library` з методами `addItem`, `findByYear`, геттером `allDescriptions` і методом `findOldest` (повертає `null`, якщо бібліотека порожня).

## Запуск

```powershell
dart run main.dart
```

## Меню

1 — додати книгу; 2 — додати журнал; 3 — показати всі видання; 4 — пошук за роком; 5 — найстаріше видання; 0 — вихід.

Вводь дані після відповідних запитів. Усі поля перевіряються на коректність. Дані зберігаються в пам'яті до завершення програми.

## Перевірка

```powershell
dart run test_library.dart
```
